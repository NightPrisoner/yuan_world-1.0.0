元世界 1.0.0 · Windows x64
==========================

怎么用
------
1. 把整个文件夹解压到任意位置（DLL、data 目录都要跟着，别只拿 exe）。
2. 双击 **元世界.exe**。

**这是一个空数据包**：里面不带任何笔记，第一次打开就是干净的空白库
（已实测：启动后自建库，笔记 0 篇、文件夹 0 个）。你自己建、自己导。

名字对得上了
------------
· 盘上的文件名：**元世界.exe**
· 窗口标题、任务管理器、任务切换器：元世界
· 右键 → 属性 → 详细信息：FileDescription / ProductName 都是元世界

（技术细节：CMake 的 target 名不能是中文，否则报
 `Cannot specify compile definitions for target "元世界"`；
 所以给 Release 产物单独设了 OUTPUT_NAME。Debug 构建仍叫 yuan_world.exe，
 不影响开发时的 `flutter run -d windows`。）

data 目录里什么能删、什么不能删
-------------------------------
    data\app.so            ← 程序本体（AOT 编译的 Dart 代码），删了打不开
    data\flutter_assets\   ← 程序资源（图标、字体…），删了打不开
    data\icudtl.dat        ← 程序依赖，删了打不开
    data\images\           ← 你导入的图片视频（第一次导入后才有）
    data\snapshots\        ← 应用内快照
    data\yuanworld.db      ← 笔记库（第一次运行后自建）

也就是说：**`data` 这个目录不能整个删掉**，程序和你的数据混在里面。
想"清空所有笔记重新开始"，删 `yuanworld.db*`、`images\`、`snapshots\`
这三样就够了。

数据在哪 / 怎么备份
-------------------
· 笔记库：`data\yuanworld.db`（SQLite）
· 图片视频：`data\images\`
· 应用内「设置 → 立即完整备份…」会打成一个压缩包；「从备份恢复…」可还原
· 全部数据都在本机，不上传任何服务器
· 手机和电脑是两份独立的库，不会自动同步 —— 换设备请用备份/恢复

可能会有的提示
--------------
这个 exe **没有代码签名**，Windows SmartScreen 可能提示"未知发布者" ——
点「更多信息 → 仍要运行」即可。要消掉这个提示需要买代码签名证书。
